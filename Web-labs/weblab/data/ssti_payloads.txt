# Server-Side Template Injection (SSTI) payloads for weblab's ssti engine.
#
# One payload per non-comment line; blank lines and lines starting with '#'
# are ignored. These probe the /render?name= sink, where user input is spliced
# into a template ("Hello {{ name }}!") and EVALUATED instead of being treated
# as inert data.
#
# A safe app substitutes the value as plain text, so "{{7*7}}" comes back as the
# literal string "{{7*7}}". The demo app evaluates it, so "{{7*7}}" renders "49"
# -- that arithmetic-being-computed IS the bug.

# --- the canonical arithmetic fingerprint (clearest detect signal) ---
# A safe app echoes these verbatim; a vulnerable one returns the PRODUCT.
{{7*7}}
{{7*'7'}}
{{6*6}}
${7*7}
#{7*7}
