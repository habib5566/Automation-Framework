    More — Mailpit, .env lines, notify token

    Local test (Mailpit): default SMTP is this PC only. Start mail: npm run go-live:mailpit:install once, then npm run go-live:mailpit in another terminal; open http://localhost:8025. Or one command: npm run go-live:audit:with-mailpit.

    Real Gmail in inbox: in project root .env add e.g. GO_LIVE_AUDIT_SMTP_PRESET=gmail, GO_LIVE_AUDIT_SMTP_USER, GO_LIVE_AUDIT_SMTP_PASS (Google App Password), GO_LIVE_AUDIT_EMAIL_FROM, restart the server. Full steps: go-live-audit/EMAIL.md.

    Notify token: only if your team set GO_LIVE_AUDIT_NOTIFY_TOKEN on the server — then paste the same secret here. Otherwise leave empty.
